HTH-GA-08: Evidence-Based Personal/SME Finance Advisor  

Category : Details 

Industry : FinTech  

Scenario : Small business owners and individuals get generic financial advice that ignores heir actual transaction patterns. 

Problem Statement : Build a GenAI advisor that analyses real transaction data (synthetic) to identify unusual spending, recurring/hidden costs, and budget violations, then generates a financial plan grounded in the actual numbers — not generic tips.

What Teams Should Build : Transaction analysis pipeline, anomaly/recurring-cost detection, goal-tracking, grounded plan generation referencing actual transactions. 

24-Hour MVP : Synthetic transaction dataset (500–2000 rows), detect anomalies/recurring charges, generate a plan citing specific transactions.  

Data/Input : Synthetic transaction data generator (teams can build or use provided template).  

Key Constraints : Advice must reference actual data points, not boilerplate; must handle irregular income patterns (SME context).  

Expected Output : Financial health report with cited evidence and prioritized action list. 

Evaluation Criteria : Groundedness, actionability, handling of edge cases (irregular income, subscriptions). 

Bonus Features : “What-if” simulator for spendin
